# Screenshots for README

Add PNG or WebP captures from the **live demo** (no real student or staff PII in titles or forms).

Suggested filenames:

| File | What to capture |
|------|-----------------|
| `calendar.png` | Events calendar with status colors |
| `events.png` | Event list or event detail |
| `inventory.png` | Inventory list or item detail |
| `dashboard.png` | Home or role-appropriate landing view |

After adding files, they appear automatically in the root `README.md` Screenshots section.
